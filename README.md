# 🐍 Snake Game

A modern, beautiful snake game built with HTML5 Canvas, CSS3, and JavaScript. Features a sleek dark theme with neon accents, smooth animations, and responsive design.

## ✨ Features

- **Modern UI**: Beautiful dark theme with gradient effects and glassmorphism design
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Multiple Difficulty Levels**: Choose from Slow, Normal, Fast, and Insane speeds
- **Score System**: Track your current score and high score (saved locally)
- **Smooth Animations**: Pulsing food, glowing snake segments, and smooth transitions
- **Keyboard & Button Controls**: Multiple ways to control the game
- **Pause/Resume**: Pause the game at any time
- **Auto-Speed Increase**: Game gets faster as you score more points

## 🎮 Controls

### Keyboard Controls
- **Arrow Keys** or **WASD**: Move the snake
- **SPACE**: Start the game
- **P** or **ESC**: Pause/Resume the game
- **R**: Restart the game

### Button Controls
- **Start Game**: Begin a new game
- **Pause/Resume**: Toggle game pause
- **Restart**: Start a new game
- **Speed Selector**: Choose game difficulty

## 🚀 How to Play

1. **Start the Game**: Press SPACE or click the "Start Game" button
2. **Move the Snake**: Use arrow keys or WASD to control direction
3. **Eat the Food**: Collect the pulsing pink circles to grow and score points
4. **Avoid Collisions**: Don't hit the walls or your own tail
5. **Score Points**: Each food item gives you 10 points
6. **Beat Your High Score**: Try to achieve the highest score possible!

## 🎯 Game Rules

- The snake grows longer each time it eats food
- Game ends if the snake hits the wall or itself
- Score increases by 10 points per food eaten
- Game speed increases every 50 points
- High scores are automatically saved in your browser
